逆命九霄美化素材

此仓库只存放角色卡公开美化图片，不包含角色设定、世界书、脚本、聊天或存档。35张原图总计约1.35MB。请保留assets目录和文件名。

使用方法：
1. 在自己的GitHub账号创建Public公开仓库。
2. 解压本包，将assets文件夹、index.html和.nojekyll上传到仓库根目录并提交。
3. 把仓库网址发回；随后可将角色卡图片改为Raw直链，并逐图检查跨域读取及浏览器兼容。

可选GitHub Pages：仓库Settings→Pages→Deploy from a branch→main、/(root)，保存并等待发布。
请不要把整个角色卡JSON或聊天存档一起上传。
Raw和Pages都依赖网络访问，不应承诺所有地区或网络始终可达。
